# Analytics-Dashboards

This repository contains three interactive business intelligence dashboards built using Power BI and Google Data Studio (Looker Studio). These projects focus on transforming raw datasets into meaningful visual insights that support business decision-making.

The dashboards cover:

Retail Sales Analysis
Bright Coffee Shop Performance
Shopping Trends & Consumer Insights

Each dashboard demonstrates skills in:

Data cleaning and transformation ,
KPI tracking,
Trend analysis,
Business reporting ,
Tools & Technologies
Microsoft Power BI ,
Google Data Studio ,
Microsoft Excel ,
Data Modeling and
Data Visualization

 ###Retail Sales Dashboard###
Description

A sales analytics dashboard designed to monitor retail business performance across different products, regions, and time periods.

Key Insights :
Total sales performance ,
Revenue trends over time ,
Best-selling products,
Regional sales comparison,
Customer purchasing behavior,
Monthly and yearly trend analysis ,
KPI cards for quick insights and
Category-wise sales breakdown

2. Bright Coffee Shop Dashboard

Key Insights :

Most popular menu items
Peak customer hours
Sales by product category
Customer purchasing trends
Features

Product performance tracking
Revenue monitoring
Time-based sales analysis
