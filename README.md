# Dashboard Projects README

## Overview

This repository contains interactive dashboards built using Microsoft Power BI and Google Data Studio.  

The dashboards focus on:
- Retail Sales Analysis
- Bright Coffee Shop Performance
- Shopping Trends & Customer Insights

These projects were created to analyze business data, track KPIs, and present insights through clear and interactive visualizations.



## Tools Used

- Microsoft Power BI
- Google Data Studio
- SQL
- Excel / CSV
- DAX


## Key Features

- Interactive dashboards
- Sales and revenue tracking
- Customer trend analysis
- Product performance insights
- Regional and category analysis
- Data filtering and drill-down reports


## Dashboard Topics

### Retail Sales Dashboard
Analyzes sales performance, revenue trends, top products, and regional sales data.

### Bright Coffee Shop Dashboard
Tracks coffee shop sales, customer behavior, popular products, and daily performance metrics.

### Shopping Trends Dashboard
Explores customer shopping patterns, seasonal trends, and purchasing behavior.


## Objective

The goal of these dashboards is to transform raw data into meaningful insights that support better business decisions and reporting efficiency.
